# 藥廠三十年：一顆藥的科學與生意

繁體中文學生教育用靜態網站，歷史範圍 1996–2025；破產／重整程序另核對至 2026-10-07。

## 內容

- 六家目的性選取的跨國藥廠，不是世界前六名排行榜
- 十二項品牌案例，區分原創、授權、共同開發、併購；Ozempic/Wegovy 是同一活性成分
- 原幣別與明確會計口徑的年度財務快照，並非 30 年完整序列
- Achaogen、Endo、Purdue 與非破產的 Shire 收購對照
- 搜尋、公司／核准年代篩選、時間軸、財務圖、五題測驗、列印摘要
- 每項資料均有原始來源連結；歷史用途不是完整當前藥品仿單

## 使用與驗證

以任意靜態伺服器提供本資料夾，或直接開啟 index.html。沒有後端、追蹤或登入。

`node check-data.cjs` 驗證來源參照、數值、日期、篩選與測驗完整性。

`research-data.json` 是可機讀來源資料；`data.js` 是網站對應資料。財務金額單位為各幣別百萬，沒有換匯。Roche/Novartis 銷售與含其他收入總收入分開；淨利歸屬也明示。

圖形和介面為原創。Google Fonts 為可選外部字型，無法載入時使用本機字型。此教材不提供個人醫療、投資或法律建議；原始機關文件如有更新，以該文件為準。
